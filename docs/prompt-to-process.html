Matrix on Operaton · configuration, not code

You describe the flow.The agent picks and arranges.Operaton runs it.

The LLM never writes BPMN, forms or code. It chooses from your predefined packages and fills in a configuration. Our platform validates that configuration, compiles it, and hands Operaton something it can execute.

Why letting an LLM do this is safe

It can only pick from a menu

Tools accept modules, tasks, fields and rules in a fixed shape. There is no tool for writing BPMN or code.

Bad configs are refused

The validator runs on every change. Errors go back to the agent, which must fix them or ask you.

It is tested before you see it

The check drives a case end to end as the real users and fails if any role can see or act on the wrong task.

You publish, not the agent

Each publish is a new version. Sites already running stay on theirs until you choose to migrate them.
